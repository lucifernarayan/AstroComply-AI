# Agent execution

The legacy LangGraph pipeline gathers catalogue state and regulation snippets, then runs orbital, collision heuristic, compliance, sustainability, forecast, mitigation and report nodes. Specialist endpoints stop after their requested node. The frontend shows returned timeline steps after execution. This legacy path has no persisted step log or cost budget yet.

Numeric orbit and heuristic risk calculations come from backend functions. The forecast is an illustrative constant-growth scenario. It withholds collision probability in the absence of uncertainty. Regulatory snippets are local lexical retrieval results. Groq interpretation requires a configured key. Operator approval must follow evidence review and an authenticated workflow before use with customer missions.

The workspace investigation path persists a queued PostgreSQL job, then a separate worker executes organization-scoped deterministic tools for conjunction, satellite, fleet health, regulatory research or mission analysis. Each result records tool steps, source identifiers and limitations. Conjunction conclusions explicitly withhold collision probability. Job status, progress, evidence, error and retry count survive API restarts. Idempotency keys prevent duplicate submissions within an organization. Regulatory search may fail when its local index is unavailable; the job records that failure. Other LangGraph assessments still execute within HTTP requests and need migration to this worker pattern.

The workspace fleet globe uses uploaded organization-owned TLEs, SGP4 propagation and Skyfield WGS84 geodetic conversion. It displays source, epoch, requested time and stale or unavailable states. It does not display an observed position. The separate legacy mission globe still uses catalogue elements and a two-body screening visualization; it is not an operational conjunction trajectory. The Moon there is decorative.
