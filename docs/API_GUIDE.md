# API guide

Run the FastAPI app from the repository root with `uvicorn backend.api.main:app --reload`. Open `/docs` for generated route schemas. `DATABASE_URL` points to PostgreSQL. `GROQ_API_KEY` enables the LLM portions of assessments. `QDRANT_HOST` connects the optional Qdrant health client. Local regulatory search reads the bundled chunk files.

`GET /satellites/search?q=...` finds catalogue objects. `POST /analyze/raw` calculates two-body derived elements and a heuristic score from input elements. `GET /assess/{norad_id}` runs the LangGraph assessment. Partial specialist routes now stop after the requested agent. `POST /propagation/tle` returns an SGP4 state vector from a supplied TLE, in TEME coordinates. Missing covariance yields no probability of collision.

The simulator routes under `/uipath` model a licensing workflow. Payment verification, registry writes and escalation are illustrative. No spacecraft command is transmitted.

Register with `POST /auth/register` using an email address and a password of at least 12 characters. Login returns an opaque bearer token. Send it in the `Authorization` header. `GET /auth/me` validates the session and `POST /auth/logout` revokes it. `GET` and `POST /organizations` list and create workspaces. Workspace fleet CRUD routes use `/organizations/{organization_id}/fleet`. Membership is checked on every request. A catalogue NORAD ID is optional when creating a customer record, and when supplied it must already exist in the catalogue.

`POST /organizations/{organization_id}/events` imports one provider supplied conjunction summary. A source and external event identifier deduplicate imports within the workspace. GET lists and details are workspace scoped, and PATCH records review status and notes. The endpoint preserves the supplied payload. It does not calculate collision probability. The UI leaves probability unavailable when missing.

`POST /organizations/{organization_id}/fleet/{asset_id}/tle` accepts a two-line TLE upload with a source label, validates checksums and catalogue number, and stores its original text and SHA-256 digest. `GET /organizations/{organization_id}/fleet/{asset_id}/elements` lists element history. `GET /organizations/{organization_id}/orbital/positions?at=<UTC timestamp>` returns SGP4 predictions for the fleet at a requested instant. The SGP4 state is in TEME; Skyfield converts it to WGS84 latitude, longitude, and altitude for the globe. TLEs more than 14 days from the requested time are marked stale and coordinates are withheld. These are predictions from mean elements, not observations or precision orbit determination.

`POST /organizations/{organization_id}/events/cdm` accepts a UTF-8 CCSDS CDM KVN or XML file up to 1 MB. The supported subset includes message originator, message ID, creation time, TCA, miss distance, optional relative speed, two object designators, and supplied covariance fields. The parser records original bytes, SHA-256 digest, filename, parser version, units, and parsed source fields. Reimporting the same bytes returns 409. Reimporting a changed message with the same provider and message ID updates the event and records a new source version. `GET /organizations/{organization_id}/events/{event_id}/versions` lists versions; `/versions/{version_number}/source` downloads the original file. Both require organization membership. This is a validated supported subset, not full CCSDS XSD validation; unsupported or incomplete input is rejected. Missing covariance and probability remain missing. [CCSDS Conjunction Data Message standard](https://ccsds.org/publications/bluebooks/entry/3064/)

`POST /organizations/{organization_id}/investigations` queues one of `conjunction_investigation`, `satellite_investigation`, `fleet_health`, `regulatory_research`, or `mission_analysis`. Conjunction requires `event_id`; satellite and mission require `asset_id`. Supply `query` and optionally an `idempotency_key`. `GET /organizations/{organization_id}/investigations/{job_id}` exposes durable status, progress, attempts, tool steps, result and error. A completed job has a protected plain text report at the `/report` suffix. Regulatory research requires the configured local search service and fails with a recorded reason when unavailable.

`GET /organizations/{organization_id}/reports/fleet.csv` and `/reports/events.csv` export real organization-owned rows. The fleet export includes catalogue epoch and available orbital elements. The event export includes provider identifiers, source file hash, measurements and import time. CSV values that spreadsheet programs could interpret as formulas are escaped. Both endpoints require organization membership.

`GET /organizations/{organization_id}/reports/fleet.pdf` and `/reports/events/{event_id}.pdf` generate protected PDFs from current database records. They include source IDs, timestamps, epochs or event values, algorithm/version notes, and quality limits. They are generated synchronously and are not retained as report records.
